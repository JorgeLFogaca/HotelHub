
# HotelHub

Motor de Reservas Hoteleiras.

## Objetivo
Sistema de gerenciamento de reservas hoteleiras,
com prevenção de overbooking e check-in digital.

## Arquitetura

- Serviço A: Reservations (Core)
- Serviço B: Live (Check-in e tempo real)
- Serviço C: Audit (Histórico e relatórios)

## Frontend

- Web: React + TypeScript + Vite
- Mobile: React Native + Expo

## Infraestrutura

- PostgreSQL
- Redis
- RabbitMQ
- Docker
